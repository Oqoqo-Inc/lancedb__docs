When using temporary or time-limited cloud credentials (such as IAM roles, temporary access keys, or namespace-managed credentials), static `storage_options` dictionaries won't work because they become invalid after expiration.

LanceDB's `StorageOptionsProvider` interface enables automatic credential refresh. The provider's `fetch_storage_options()` method is called by LanceDB to get fresh credentials before they expire.

## The StorageOptionsProvider interface

The `StorageOptionsProvider` abstract base class requires implementing a `fetch_storage_options()` method that returns a dictionary of storage options:

<CodeGroup>
<CodeBlock language="Python" title="Custom StorageOptionsProvider" icon="python">
import os
from lancedb.io import StorageOptionsProvider

class MyProvider(StorageOptionsProvider):
    def fetch_storage_options(self) -> Dict[str, str]:
        # Fetch fresh credentials from your credential manager
        # This could be from environment variables, AWS STS, or a secrets service
        return {
            "aws_access_key_id": os.environ.get("AWS_ACCESS_KEY_ID"),
            "aws_secret_access_key": os.environ.get("AWS_SECRET_ACCESS_KEY"),
            "expires_at_millis": "1700000000000"  # Optional: Unix timestamp in milliseconds
        }

db = lancedb.connect(
    "s3://my-bucket/path",
    storage_options_provider=MyProvider(),
)
</CodeBlock>
</CodeGroup>

### expires_at_millis for automatic refresh

If you include an `expires_at_millis` key in the returned dictionary, LanceDB will automatically call `fetch_storage_options()` before that time to refresh credentials. If omitted, credentials are assumed to be static.

## When to use StorageOptionsProvider

Use `StorageOptionsProvider` instead of static `storage_options` when:

- **Temporary credentials**: IAM roles, assume-role sessions, or short-lived access keys
- **Namespace-managed credentials**: LanceDB Cloud or on-prem namespace service
- **Credential rotation**: You want automatic refresh without restarting your application
- **Long-running operations**: Operations that may outlive credential validity

## Rust API

In Rust, use `Arc<dyn StorageOptionsProvider>` with the builder patterns:

```rust
use std::sync::Arc;
use lancedb::connection::OpenTableBuilder;

let provider: Arc<dyn StorageOptionsProvider> = /* your provider */;

let table = db
    .open_table("my_table")
    .storage_options_provider(provider)
    .execute()
    .await?;
```
