When using temporary or time-limited cloud credentials (such as IAM roles, STS session tokens, or namespace-managed credentials),
you can implement a custom `StorageOptionsProvider` to automatically refresh credentials before they expire.
This is essential for long-running operations or scheduled jobs that need to access cloud storage.

## How it works

A `StorageOptionsProvider` is an object with a `fetch_storage_options()` method that LanceDB calls whenever credentials need to be refreshed.
The method returns a dictionary of storage options, optionally including an `expires_at_millis` timestamp that tells LanceDB when to fetch fresh credentials.

## Python API

### StorageOptionsProvider class

The `lancedb.io.StorageOptionsProvider` is an abstract base class you implement:

```python
from lancedb.io import StorageOptionsProvider

class MyProvider(StorageOptionsProvider):
    def fetch_storage_options(self) -> dict:
        # Fetch fresh credentials from your credential manager
        return {
            "aws_access_key_id": "...",
            "aws_secret_access_key": "...",
            "region": "us-east-1",
        }
```

### Using with create_table and open_table

Both `create_table()` and `open_table()` accept a `storage_options_provider` parameter:

```python
import lancedb
from lancedb.io import StorageOptionsProvider

class MyCredentialProvider(StorageOptionsProvider):
    def fetch_storage_options(self) -> dict:
        # Fetch fresh credentials from your credential manager
        return {
            "aws_access_key_id": "your-access-key",
            "aws_secret_access_key": "your-secret-key",
            "region": "us-east-1",
        }

db = lancedb.connect("s3://my-bucket/my-database")
table = db.create_table(
    "my_table",
    data,
    storage_options_provider=MyCredentialProvider(),
)
```

### With expiration timestamps

Include `expires_at_millis` to enable automatic refresh:

```python
import time
from lancedb.io import StorageOptionsProvider

class ExpiringCredentialProvider(StorageOptionsProvider):
    """Provider with automatic refresh based on expiration."""

    def fetch_storage_options(self) -> dict:
        # Return credentials with expiration
        return {
            "aws_access_key_id": "temporary-access-key",
            "aws_secret_access_key": "temporary-secret-key",
            "session_token": "temporary-session-token",
            "expires_at_millis": str(int((time.time() + 3600) * 1000)),  # 1 hour
        }

db = lancedb.connect(
    "s3://my-bucket/my-database",
    storage_options_provider=ExpiringCredentialProvider(),
)
```

LanceDB automatically refreshes credentials before the `expires_at_millis` timestamp.

### LanceNamespaceStorageOptionsProvider

For namespace-connected environments, use `LanceNamespaceStorageOptionsProvider` which fetches time-limited credentials from the namespace service:

```python
from lancedb.io import StorageOptionsProvider
from lancedb.namespace import LanceNamespaceStorageOptionsProvider
from lance_namespace import connect as namespace_connect

# Connect to namespace
namespace = namespace_connect("rest", {"uri": "https://namespace.example.com"})

# Create provider for automatic credential refresh
provider = LanceNamespaceStorageOptionsProvider(
    namespace=namespace,
    table_id=["my_namespace", "my_table"]
)

# Use with create_table or open_table
db = lancedb.connect(
    "s3+namespace://my-bucket/my-database",
    storage_options_provider=provider,
)
```

## Rust API

In Rust, implement the `StorageOptionsProvider` trait and pass it to the connection or read params:

```rust
use lancedb::StorageOptionsProvider;
use std::sync::Arc;

struct MyProvider;

impl StorageOptionsProvider for MyProvider {
    fn fetch_storage_options(&self) -> Result<std::collections::HashMap<String, String>> {
        // Fetch fresh credentials
        Ok([
            ("aws_access_key_id".to_string(), "your-access-key".to_string()),
            ("aws_secret_access_key".to_string(), "your-secret-key".to_string()),
        ].into_iter().collect())
    }
}

// With connection
let db = lancedb::connect("s3://my-bucket/path")
    .storage_options_provider(Arc::new(MyProvider))
    .await?;

// With read params
let mut read_params = lancedb::ReadParams::default();
read_params.storage_options_provider = Some(Arc::new(MyProvider));
let table = db.open_table("my_table").with_params(read_params).execute().await?;
```

## When to use StorageOptionsProvider

Use `storage_options_provider` instead of static `storage_options` when:

- Using temporary credentials (STS, IAM roles, assume role sessions)
- Credentials have a defined expiration time
- Running long-lived processes that need to outlast credential validity
- Accessing tables through a namespace service with managed credentials

For static, long-lived credentials, use the simpler `storage_options` dictionary instead.
